# 帮战数据分析（本地网页）

> 江山如画 萧玖凤制作（另：渡江云招pvp玩家，帮会内氛围好，每天都会带寄到，不压力人，没有小团体）

纯前端，**双击 `index.html` 即可用**，不装东西、不联网、数据不出本机。

## 用法

1. 双击 `index.html`（Chrome / Edge）。
2. 把 CSV / Excel **直接拖进去**，或点「导入 Excel」。想先看效果就点「示例数据」。
3. 「成员分析」里点任意一行 → 弹出该成员的**五维雷达**（本人 / 门派均值 / 全队均值）+ 对比表。
4. 「联赛对比」看双方大屏。

## ⭐ 直接吃游戏的原生战报导出

从游戏里导出的 `20261010_205223_示例帮会甲_示例帮会乙.csv` **原封不动拖进去就行**，不用先整理：

```
"示例帮会甲","55"                        ← 段头：帮会名 + 人数
"玩家名字","职业","击败/清泉","助攻",...   ← 列名
"示例玩家","铁衣"," 0/0","94",...         ← 数据
                                          ← 空行分隔
"示例帮会乙","60"                        ← 下一个帮会
...
```

工具会自动：
- 识别**多个帮会分段**，把帮会名补成一列（一次看全 115 人）
- 拆 `击败/清泉`、`复活/清泉` 这种斜杠列，**取斜杠左边的值**
- 按 UTF-8 解码（中文不乱码），并禁止把 `" 5/1"` 误当成日期

### 列名对应

| 战报里的列 | 工具里叫 |
|---|---|
| 玩家名字 | 角色名 |
| 职业 | 门派 |
| 击败/清泉 | 击败（取左值） |
| 助攻 | 助攻 |
| 对玩家伤害 | **人伤** |
| 对建筑伤害 | **塔伤** |
| 承受伤害 | **承伤** |
| 治疗值 | 治疗 |
| 重伤 | **重伤**（雷达里换算成「生存」） |
| 复活/清泉、资源、人伤卸甲、破塔卸甲、焚骨 | 保留，可在「字段设置」里用 |

> 换成别的列名也没关系：`app.js` 顶部 `FIELDS` 的 `aliases` 里加词即可；实在认不出就点「字段设置」手动指列。

### 鸿音自动区分 D 鸿 / 奶鸿

战报里鸿音只有一个门派名，不区分流派。本工具会按数据自动判断并在门派列标出来：

- **奶鸿**（治疗鸿音）：`治疗值 > 0` 且 `治疗值 > 人伤 + 塔伤` → 显示为「鸿音·奶」
- **D 鸿**（输出鸿音）：其余情况 → 显示为「鸿音·D」

细分后，筛选、门派占比环形图、各门派分组柱状图、个人雷达的「同门派均值」都会自动把两类分开统计。页面顶部有对应说明条，仅供参考。

## 两个页面

### 成员分析
| 区域 | 说明 |
|---|---|
| 成员表 | 序号 / 角色名 / 门派 / 帮会 + 人伤 · 塔伤 · 承伤 · 重伤 · 击败 · 助攻 · 治疗 · KDA · 每死承伤，点表头排序 |
| 筛选 | 搜索、按门派筛、按帮会筛 |
| 五维雷达弹窗 | 「综合 / 进攻 / 防守」三套口径，鼠标悬停看具体数值 |
| 对比表 | 数据维度 \| 本人 \| 占比 \| 门派均值 \| 全队均值 \| 对比门派 |

雷达口径：每个维度以「**全队人均 = 100**」为基准，三条线同尺度可直接比；虚线正多边形就是全队平均线。

三套雷达维度（没有数据的维度会自动跳过）：
- **综合**：人伤 / 生存 / 承伤 / 塔伤 / 助攻
- **进攻**：人伤 / 塔伤 / 击败 / 每死输出 / 助攻
- **防守**：承伤 / 每死承伤 / 生存 / 治疗 / 每死输出

### 联赛对比
- 4 个对比数字（总击败 / 总人伤 / 总塔伤 / 总重伤……）：我方蓝、敌方红
- **团队能力对比雷达**（双方两条线）
- 我方 / 敌方 阵容人数环形图
- 各门派分组柱状对比：人伤产出 / KDA / 重伤人数 / 每死输出 / 承伤 / 塔伤

> **我方帮会**默认自动选中**人数最多**的帮会（对手每场都换，下拉切换即可）。
>
> **口径**可切「总量 / 人均」：
> - **总量**（默认）：各族合计，跟顶部 KPI 对得上
> - **人均**：各族平均值，适合比不同规模的帮会
> - KDA / 每死输出 / 每死承伤 这类比值指标固定用「总分子 ÷ 总分母」，不受口径影响

> 窄屏（如 1280×800 笔记本 @150% 缩放 ≈ 850px）会自动切成**单列**，
> 保证 11 个门派标签能完整显示。
